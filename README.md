# Job Hunt Tracker

A job application tracker that runs entirely in your browser. It's one HTML file with no server, no account and no internet connection needed.

**Live demo:** https://stevens681.github.io/job-hunt-tracker/

## Features

- **Pipeline board:** color-coded stages (Wishlist, Applied, Screening, Interviewing, Offer, Accepted, Rejected, Withdrawn). Drag cards between columns or change the stage from the label on each card.
- **Automatic follow-ups:** moving a card to Applied, Interviewing or Offer adds the next task (follow up, send thank-you notes, review the offer).
- **Resume versions:** store each tailored resume (PDF or Word) and link it to the applications you sent it to.
- **Knowledge base:** STAR stories, company research, interview Q&A and email templates, searchable and linkable to applications.
- **Tasks:** grouped into Overdue, Today, Next 7 days and Later.
- **Stats:** applications in progress, response rate and how many reached an interview.
- **Light and dark mode:** Auto, Light or Dark.
- **Export:** applications and tasks as CSV for Excel or Google Sheets, plus a full JSON backup (resume files included) that you can import on another computer.

## Use it

Download `index.html` and open it in Chrome, Edge or Firefox, or use the live demo.

Your data is saved in your browser's local storage (IndexedDB) on your computer. Nothing is uploaded anywhere. Clearing your browser data erases it, so use **Export backup** now and then.

## Built with

Plain HTML, CSS and JavaScript with no dependencies.
